TailCopy 0.3.1 fixes a bug on Linux desktops running X11. Install it over 0.3.0 or
0.2.4; your history is kept.

## Download

| System | File |
| --- | --- |
| Windows 10 (22H2) and 11, x64 | `TailCopy-0.3.1-windows-x64-setup.exe` |
| macOS 13 and later, Apple silicon and Intel | `TailCopy-0.3.1-macos-universal.dmg` |
| Ubuntu 24.04 and 26.04, GNOME on Wayland | `TailCopy-0.3.1-ubuntu-amd64.deb` (includes the GNOME extension) |
| Other Linux desktops on X11, based on Ubuntu 24.04 (best effort) | the same `.deb` |

Check downloads against `SHA256SUMS`.

## Fixed

- **X11: other apps stopped opening windows after a while.** On X11, TailCopy opened
  two new connections to the display every time something was copied and never closed
  them. After enough copies the display ran out of connections, and apps started
  failing with "Maximum number of clients reached". TailCopy now keeps a single
  connection open. If you've seen this, restart TailCopy (or log out and back in)
  after updating. GNOME on Wayland, Windows and macOS weren't affected.

If you're on 0.2.4 or later, TailCopy tells you about this update by itself.
